# m-analytics-projects
В этом репозитории содержатся мини проекты по аналитике данных.

## 1. Candy hierarchy in 2017
Это проект по очистке и анализу данных с датасета [**So Much Candy Data, Seriously**](https://www.scq.ubc.ca/so-much-candy-data-seriously/), предоставленного **David Ng**. Для обработки данных используется язык Python и библиотеки Pandas и Numpy. Подробнее см. в [candy_data](candy_data).
