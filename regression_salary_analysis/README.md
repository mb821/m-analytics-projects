# Регрессионный анализ (взаимосвязи между опытом работы и зарплатой)

Датасет можно найти [по ссылке](https://www.kaggle.com/datasets/abhishek14398/salary-dataset-simple-linear-regression).

В [датасете](Salary_dataset.csv) есть столбцы 
- YearsExperience - опыт работы сотрудника (в годах)
- Salary - зарплата сотрудника

Целью данного проекта является изучение взаимосвязи этих показателей. Сначала математически, а затем программно (используя метод linregress библиотеки scipy) находится коэффициент детерминации этих переменных и проверяется статистическая значимость их зависимости.
