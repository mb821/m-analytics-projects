# A/B тест

Задача и данные взяты с [kaggle.com](https://www.kaggle.com/datasets/sergylog/ab-test-data).

> Дан [датасет](data/AB_Test_Results.csv) с полями 
> * USER_ID - пользователь
> * VARIANT_NAME - тип выборки (экспериментальная или контрольная)
> * REVENUE - доход, который принес пользователь
> 
> Некий сайт запустил A/B-тест с целью увеличения дохода. Необходимо проанализировать результаты эксперимента и написать свои рекомендации.

В блокноте [AB_test.ipynb](AB_test.ipynb) представлено полное решение задачи с кодом на языке Python и аналитическими выводами и рекомендациями для данного теста.

1. В первой части блокнота, "**Подготовка данных**", данные обрабатываются на предмет пропусков, несовпадения типов, повторов и разбиения на выборки.

2. Во второй части, "**Анализ данных**", строится гипотеза, вычисляются метрики и p-значение, указывается результат анализа теста и выводы для компании.
