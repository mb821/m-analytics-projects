# Обработка датасета Retail Store Sales

Датасет можно найти на [kaggle.com](https://www.kaggle.com/datasets/ahmedmohamed2003/retail-store-sales-dirty-for-data-cleaning).

> [Набор данных](data/retail_store_sales.csv) о продажах в розничных магазинах Dirty содержит 12 575 строк синтетических данных, представляющих транзакции продаж в розничном магазине. Набор данных включает восемь категорий товаров по 25 наименований в каждой категории, каждая из которых имеет статические цены. Он предназначен для моделирования реальных данных о продажах, включая преднамеренные "искажения", такие как пропущенные или несогласованные значения.

В блокноте [retail.ipynb](retail.ipynb) представлена работа по обработке этих данных:
1. очистка данных
2. визуализация и разведочный анализ данных
